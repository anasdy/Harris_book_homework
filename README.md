# Harris_book_homework
Exercises from book Harris and Harris "Digial design and computer arcitecutre" 

Здесь будут решения упражнений из книги Харрис и Харрис "Цифровая схемотехника и архитектура компьютера", требующие написания программного кода или которые по иным причинам удобно решать с использованием компьютера.
Задачи разделены по главам и по языкам программирования.
Для каждой главы упражнения выполняются на двух языках VHDL и SystemVerilog.
Поэтому для каждой главы создан свой каталог в котором находятся два каталога для каждого из языков программирования. А уже внутри этих двух каталогов сщздаются папки с проектами для упражнений. Упражнения пронумерованы так же, как это сделано в книге.
